# SJourney – React + Tailwind (Vite)

## Run
    npm install
    npm run dev       # http://localhost:5173
    npm run build     # production build in /dist

## Structure
- src/components – TopBar, Navbar, Hero (carousel), Welcome, SignatureRoutes, PhotoGallery, FloatingWidgets
- src/assets/logos – SJourney logo, Tailormade Journeys logo
- src/assets/images – hero carousel images
- PlaceholderSvg.jsx – temporary images for the Welcome video, route cards and gallery;
  replace each <PlaceholderSvg /> with an <img> when you have the real photos.
